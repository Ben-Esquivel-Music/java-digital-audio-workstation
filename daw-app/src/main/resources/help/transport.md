# Transport Controls

The transport controls drive playback, recording, and looping for the entire
session.

## Buttons

- **Play** — start playback from the current playhead position.
- **Stop** — stop playback and (optionally) return to the start.
- **Record** — arm record on enabled tracks and start the transport.
- **Loop** — repeat playback between the locator markers.
- **Loop Rec** — with the loop enabled, record every loop pass as its own
  take lane under the track; the last whole pass plays until you comp.
- **Metronome** — toggle the click track.

## Keyboard shortcuts

```
Space      Play / Stop
R          Record
L          Toggle loop
Shift+L    Toggle loop record
M          Toggle metronome
I          Set punch-in at the playhead
O          Set punch-out at the playhead
Shift+P    Toggle the punch region on/off
```
